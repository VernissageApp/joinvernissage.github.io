Vernissage extensions to ActivityPub for photo-centric Applications

Abstract. This document describes a set of JSON object extensions used in the ActivityPub protocol by the Vernissage platform. These extensions are designed to support photo-centric use cases by adding metadata relevant to image handling, location tagging, and categorization. While not part of the core ActivityPub specification, these extensions aim to be interoperable and safely ignored by clients that do not support them.

1. Introduction

The Vernissage platform introduces additional fields to ActivityPub objects to enhance the experience of publishing and consuming photographic content. These extensions are primarily intended for applications focused on photography and visual media. The fields are added using custom context definitions and are compatible with the ActivityStreams JSON-LD structure.

The full @context definition including all custom terms is as follows:


"@context": [
  "https://www.w3.org/ns/activitystreams",
  {
    ... (other extensions) ...
    "photos": "https://joinvernissage.org/ns#",
    "location": "photos:location",
    "metadata": "photos:metadata",
    "category": "photos:category"
  }
]

2. Location

The location extension allows an approximate city-level location to be attached to photo attachments. The provided location is coarse enough to preserve user privacy while still offering contextual value.

Example:


"attachments": [{
  ... (standard attachment properties) ...
  "location": {
    "country": {
      "code": "PL",
      "name": "Poland"
    },
    "latitude": "51.1",
    "longitude": "17.03333",
    "name": "Wrocław"
  }
}]

2.1 Properties

  • location:name — City name.
  • location:country:code — ISO 3166-1 alpha-2 country code.
  • location:country:name — Country name.
  • location:latitude — Approximate latitude of the city.
  • location:longitude — Approximate longitude of the city.

If the location field is used, all of the above properties are required.

3. Metadata (EXIF)

The metadata extension allows inclusion of photographic metadata (commonly known as EXIF) to assist in cataloging, editing, and analysis of images. This may include camera parameters and GPS location. Inclusion of GPS metadata must be explicitly acknowledged by the user due to its precision and privacy implications.

Example:


"attachments": [{
  ... (standard attachment properties) ...
  "metadata": {
    "exif": {
      "createDate": "2025-02-27T17:38:49.408Z",
      "exposureTime": "1/200",
      "fNumber": "f/2.2",
      "flash": "Flash did not fire, compulsory flash mode",
      "focalLenIn35mmFilm": "85",
      "focalLength": "85",
      "latitude": "51.110501666666664N",
      "longitude": "17.033457778333332E",
      "lens": "Zeiss Batis 1.8/85",
      "make": "SONY",
      "model": "ILCE-7M4",
      "photographicSensitivity": "3200",
      "software": "Capture One Macintosh"
    }
  }
}]

3.1 Properties

  • metadata:exif:createDate — ISO 8601 timestamp of photo creation.
  • metadata:exif:exposureTime — Exposure time (e.g., "1/100" or "4" for 4 seconds).
  • metadata:exif:fNumber — Aperture value (e.g., "f/1.8").
  • metadata:exif:flash — Descriptive flash usage string.
  • metadata:exif:focalLenIn35mmFilm — 35 mm equivalent focal length.
  • metadata:exif:focalLength — Focal length as reported by the camera.
  • metadata:exif:latitude — Exact latitude of photo location.
  • metadata:exif:longitude — Exact longitude of photo location.
  • metadata:exif:lens — Lens model name.
  • metadata:exif:make — Camera manufacturer.
  • metadata:exif:model — Camera model.
  • metadata:exif:photographicSensitivity — ISO sensitivity.
  • metadata:exif:software — Editing software used.

All of these fields are optional. However, due to the sensitive nature of latitude and longitude, platforms must clearly inform the user and obtain consent before including them.

4. Category

The category field allows classification of a post using a plain-text tag representing the photo’s category or genre.

Example:


{
  ... (standard note properties) ...
  "category": {
    "name": "Black and white"
  }
}

4.1 Properties

  • category:name — Name of the photo’s category.
